## Purpose

This register tracks every V2 provision that amends a V1 governing requirement, per the Operator decision in `V2_DOCUMENT_PRECEDENCE_ADOPTION_RECORD.md`.

A V2 document may amend a V1 requirement **only** when it:
1. Explicitly identifies the affected V1 document and section(s)
2. States the prior rule
3. States the replacement/amended rule
4. Defines effective scope and date
5. Is approved through the established governance process
6. Is recorded in this register

---

## Entry Format

| Field | Description |
|-------|-------------|
| Amendment ID | `V2-AMD-NNN` |
| Date | Date of approval |
| Affected V1 Document | Exact filename |
| Affected V1 Section(s) | Section number(s) |
| Prior Rule | The V1 rule being amended |
| Replacement Rule | The new rule |
| Effective Scope | What the amendment applies to |
| Approving Authority | Operator / ITRGA |
| Governing Process | Reference to approval process |
| Status | Active / Superseded / Retired |
