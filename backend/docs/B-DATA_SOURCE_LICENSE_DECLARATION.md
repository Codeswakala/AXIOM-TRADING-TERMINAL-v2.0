## Source 1 — OKX public market data (deep H1)

- **Source:** OKX, public market-data endpoint `GET https://www.okx.com/api/v5/market/history-candles` (candlestick history; parameter `bar=1H`).
- **Instruments:** BTC-USDT, ETH-USDT, SOL-USDT, XRP-USDT, ADA-USDT, DOGE-USDT — spot, hourly OHLCV, 2024-08-01T00:00Z → 2026-08-01T00:00Z, **17,520 bars per instrument** (complete window, zero missing hours across the retrieval).
- **License / terms reference:** OKX Terms of Service (okx.com/help/terms-of-service) and the OKX API documentation for public market data. Public market-data endpoints are documented for keyless public access. OKX's terms govern use of its services and data; no explicit open-data license is granted by OKX.
- **Permitted-use statement (honest, bounded):** the corpus is retrieved from publicly accessible endpoints for **internal research and pipeline validation within this project only**. The data is pinned and hash-recorded; it is **not redistributed** as a data product and no derivation of it is published as market data.
- **Candidate-class basis:** this is the "public exchange historical klines" candidate class the BO names — retrieved via the exchange's own public API, unmodified.

## Source 2 — Kraken public market data (2-year D1)

- **Source:** Kraken, public market-data endpoint `GET https://api.kraken.com/0/public/OHLC` (`interval=1440`).
- **Instruments:** XBTUSD, ETHUSD, SOLUSD, XRPUSD, ADAUSD, DOGEUSD — daily OHLCV, **701 bars per instrument** (2024-08-30 → 2026-07-31 within the retrieval window; the exchange's daily window starts 2024-08-30, disclosed honestly).
- **License / terms reference:** Kraken Terms of Service (kraken.com/legal) and the Kraken public REST API documentation (docs.kraken.com). Public OHLC endpoints are documented for keyless public access.
- **Permitted-use statement (honest, bounded):** identical posture to Source 1 — internal research use only, pinned and hash-recorded, not redistributed.
- **Known limitation (disclosed):** Kraken's public H1 window is depth-limited to the most recent ~720 bars (verified empirically during retrieval), which is why OKX supplies the deep H1 corpus and Kraken supplies the daily corpus.

## Lawfulness boundary (per BO §0 — binding)

Data licensing is a **legal matter**. The DA has documented each source, its endpoint, its terms reference, and the bounded use above. **The Operator retains final responsibility for the lawfulness of this use under each exchange's terms**; ITRGA verifies provenance, honesty, and reproducibility — it does not and cannot issue a legal opinion. No data was retrieved from any source whose terms the DA identified as prohibiting this use (note: Binance was probed and **rejected** — its API refused service from this environment citing its terms' eligibility clause, which the DA treats as dispositive).

## Honesty attestations (binding)

1. Every bar is written **exactly as returned** by the source; unconfirmed OKX candles (confirm flag ≠ 1) were excluded; no gap-filling, no interpolation, no synthetic backfill, no relabeling.
2. All rows are ingested with the explicit label `source="historical:real"` → `SourceAuthority.AUTHORITATIVE` (the only label that grants authority, per BO-B-DATA Part A).
3. The corpus cannot be regenerated byte-identically (real data moves); it is therefore **pinned**: per-file SHA-256 in `tests/fixtures/bdata_corpus/MANIFEST.json` (itself hash-recorded).
